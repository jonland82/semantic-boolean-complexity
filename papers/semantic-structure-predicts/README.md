# Semantic Structure Predicts Exact Boolean Formula Complexity

The original four-page paper establishes strict semantic prediction of exact
minimum formula size over all 65,536 four-input functions.

- [Read the mobile-friendly HTML edition](index.html)
- [Open the PDF](note.pdf)

Build from this directory with:

```powershell
latexmk -pdf note.tex
```

Numerical results and figures are generated by
`experiments/four_bit/scripts/run.py`.
