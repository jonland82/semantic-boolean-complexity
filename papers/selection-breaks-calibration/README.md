# When Selection Breaks Calibration

This short paper develops the six frozen cost-14 misses as an exact finite
case study in selection-induced calibration failure. Its central ingredients
are the one-gate headroom identity, top-score enrichment, and the observed
construction--semantics discordance.

Compile from this directory:

```powershell
latexmk -pdf selection-breaks-calibration.tex
```

The reproducible structural audit is generated by:

```powershell
python experiments/selective_slack_refinement/scripts/analyze_cost14_failures.py
```
